Drop Aurora's sprites here as PNG files and the app picks them up automatically:

- `neutral.png` - the main picture (used when nothing else matches)
- `speaking.png` - optional, shown while she talks
- `happy.png`, `surprised.png`, `angry.png`, `sad.png`, `sleepy.png`, `error.png` - optional extra expressions

Until `neutral.png` exists, the app icon is used.
